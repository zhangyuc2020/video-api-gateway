端点

        

          
方法与路径说明返回

          
            

              POST /v1/videos/generations
              生成视频。默认异步
              202 带 id
            

            

              GET /v1/videos/generations/{id}
              查任务状态与结果
              200
            

            

              GET /v1/models
              可用模型（只列免费档）
              200
            

            

              GET /v1/credits
              号池可用账号数
              200
            

            

              POST /v1/files
              上传素材，拿公网链接（multipart）
              200 带 url
            

          
        

        

          这个服务只跑 0 积分档：480P / 720P，时长 2–30 秒，任意画幅。
          1080P 和 prime 会扣积分，直接 400 拒绝，不静默降级。
        

      


      
      

        
请求参数

        

          
字段类型默认说明

          
            
promptstring—提示词。和 media 至少给一个

            
modelstringwan-3.0-video只接受这一个值

            
resolutionstring720P480P / 720P

            
durationint5-1（智能）或 2~30

            
ratiostringadaptive16:9 9:16 1:1 4:3 3:4 adaptive

            
audioboolfalse输出是否含音轨

            
negative_promptstring—负向提示词

            
seedint—0~2147483647

            
enable_thinkingboolfalse深度思考

            
watermarkboolfalse是否加水印

            
prompt_extendbool—提示词智能改写（网关不保证生效）

            
waitboolfalsetrue = 同步等出片再返回

          
        

      


      
      

        
素材字段

        

          
字段类型说明

          
            
start_framestring首帧图 URL

            
end_framestring尾帧图 URL（必须配 start_frame）

            
image_urlsarray参考图。元素是 URL，或 {url, name}

            
video_urlsarray参考视频，同上

            
audio_urlsarray参考音频，同上

            
mediaarray上游原生数组，{type, url, name?}

          
        

        

          也接受单数字段 image / video / audio_url。
          别名：aspect_ratio 等价 ratio；size: "1280x720" 会换算成 ratio。
        

      


      
      

        
素材引用：图N / @名字

        

          素材按数组顺序编号，图片、视频、音频分别计数。
          数组 [图, 视频, 图, 图] → 编号为 图1、视频1、图2、图3。
          两个及以上素材时必须写明编号；只有一个时可简写。
        

        

        

          给素材起 name 后可在 prompt 里用 @名字 引用，服务会自动换成 图N
          并附上「素材对应」说明。name 不会上传，上游只认 图N。
        

      


      
      

        
素材组合规则

        

          

            
允许

            
    
              
  • 参考图 / 视频 / 音频自由组合
    • 
              
  • file 或 link 可与 reference_* 组合
    • 
              
  • 仅 first_frame，或 first_frame + last_frame
    • 
            

          

          

            
禁止（本地拦下，400）

            
    
              
  • 首尾帧与任何其他素材混用（含 file / link）
    • 
              
  • file 和 link 同时出现
    • 
              
  • 只有 last_frame 没有 first_frame
    • 
            

          

        

        

          数量上限：参考图 10 · 参考视频 5 段（总时长 ≤15s）· 参考音频 5 段（≤15s）·
          首/尾帧各 1 · file / link 各 1。
        

        

          格式：图片 JPEG/PNG(无透明)/BMP/WEBP，单边 240–8000px，≤20MB；
          视频 mp4/mov，单段 1–15s，≥16fps，≤100MB；
          音频 wav/mp3，单段 1–15s，≤15MB。

  "object": "video.generation",

查询进行中：

        
{
  "id": "vtask_3e9318bbfe9f4e2a8654dff3",
  "status": "in_progress",
  "model": "wan3.0-video",
  "resolution": "720P",
  "created": 1792775030,

查询完成：

        
{
  "id": "vtask_3e9318bbfe9f4e2a8654dff3",
  "status": "completed",
  "progress": 100,
  "url": "https://gcdn.picsart.com/editing-temp/xxx.mp4",
  "elapsed": 91.1
}

        

          
status含义

          
            
queued已入队，等号池分配账号

            
in_progress上游生成中，progress 是百分比

            
completed完成，url 可用

            
failed失败，error 说明原因

          
        

        

          轮询间隔 10–15 秒。任务本身耗时数分钟，轮询太快没意义还会被限流。
          progress 来自上游真实进度（0–100），上游到 80% 算完成，这里归一到 100。
        

      


      
      

        
错误码

        

          
HTTPdetail 示例处理

          
            
4001080P 要扣积分（5 秒 30 积分）…改 480P / 720P

            
400resolution 只能是 480P / 720P，收到 '2K'按提示改

            
400media.0.type 必须是 … 之一素材类型非法

            
400首尾帧…不能和其他任何素材混用二选一

            
400prompt 或至少一个媒体输入必填补内容

            
401invalid api key检查 key

            
402额度不足（402）。免费档只能用 480P / 720P换号或等恢复

            
429该账号并发被占用（同时只能跑 1 个任务）退避重试

            
503号池无可用账号（全部忙 / 冷却 / 失效）稍后重试 / 补号

            
503上游并发名额被占用（该账号有任务在跑…）退避 30s+ 重试

          
        

        

          错误文案是全中文人话，不透出上游 reason code。
        

      


      
      

        
注意事项

        
    
          
  • 并发：每个 Picsart 账号同时只能跑 1 个任务，号池里 N 个号 = N 路并发。池子全忙返回 503，不是 429（429 只在提交瞬间撞上占用时出现）。
    • 
          
  • 耗时：实测 5 秒视频 91 秒 ~ 23 分钟，取决于上游排队，不要假设固定时长。
    • 
          
  • 成片 URL：指向 gcdn.picsart.com，可直接下载，但上游可能清理临时目录 —— 建议自行转存。
    • 
          
  • 不保证幂等：网络重试可能重复提交，请用返回的 id 去重，不要盲目重发 POST。
    • 
          
  • prompt_extend：会转发给上游但不保证生效（网关不做类型校验），想稳定控制输出就用明确的 prompt。
    • 
          
  • 与阿里云官方文档的差异（以本服务为准）：官方 ratio 支持 21:9，Picsart 不支持；官方 seed 支持 -1，这里必须 0 起；官方 duration 有「输入视频总时长+输出时长≤30」的组合约束，这里只做枚举校验。
