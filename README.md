# Video API Gateway

把自己的 Picsart 账号变成 OpenAI 风格的视频生成接口。**免费档（480P / 720P）不消耗积分。**

部署成你自己的网页应用，账号池跑在你自己机器上，账号也只有你自己能访问。

---

## 这是什么

你有一批 Picsart 账号。这个程序把它们组成一个"账号池"，对外提供一个
OpenAI 风格的 HTTP 接口：

```bash
curl -X POST "https://你的域名/v1/videos/generations" \
  -H "content-type: application/json" \
  -d '{"prompt": "一只狗在海边奔跑", "resolution": "720P", "duration": 5}'
```

返回一个任务 id，轮询拿到成片 URL。

Picsart 单账号同一时间只能跑 1 个任务。**N 个账号 = N 路并发**，
这就是"账号池"的价值。

## 快速开始

### 你需要

- 一个能部署 Web 应用的平台（WorkBuddy / 云服务器 / 自己的 VPS）
- **能访问 picsart.com 的网络环境**（境外网络或代理，见下文）
- 一个 Picsart 账号
- 一个激活码（联系发卡方）

### 三步部署

**1. 拿到代码**

下载本仓库（`Code` → `Download ZIP`），或用 Release 里的 zip。

**2. 发布**

在你的平台上，用这个目录发布，参数照抄：

| 项目 | 值 |
|---|---|
| 语言 / language | `python` |
| 启动命令 / startCmd | `python workbuddy/entry.py` |
| 端口 / port | `3000` |
| 安装依赖 / installCmd | `pip install -r requirements.txt` |

> ⚠️ **启动命令不要改成 uvicorn**
>
> 错的：`python -m uvicorn app.main:app`
> 对的：`python workbuddy/entry.py`
>
> 这个程序必须在启动时先取一次配置再加载主程序。用 uvicorn 直起会跳过
> 这一步，结果是**应用能打开、但所有功能都是坏的** —— 每次调用都会拼出
> 一个不完整的地址然后报 400，而日志里看不出任何异常。

**3. 激活**

打开发布得到的链接，会看到「激活本应用」，页面上有一串 32 位字符
（**部署标识**）。把它发给发卡方换激活码，填进去即可。

激活后**直接进管理页，不需要登录密码**。

## 第一次用之前：先测网络

打开：

```
https://你的域名/__probe
```

它会从**你部署的那台机器**出发去连 Picsart，几秒后返回一段 JSON。
看第一行的 `verdict`：

| verdict | 含义 | 该做什么 |
|---|---|---|
| 上游可达，可以正常加号和出片 | 一切正常 | 继续 |
| api 通但 auth 不通 | 能跑任务，加不了新账号 | 多试几次 |
| **上游完全不通** | **这台机器用不了** | **换网络环境重新部署** |

> 为什么必须先测：这个程序每一步都要访问 picsart.com。
> 如果部署环境连不上，后面所有操作都会失败，而报错信息会很含糊。
> 先花 30 秒测一次，能省掉几小时排查。

它会分别用「直连」和「走代理」各测一遍，所以你能直接看出是哪种方式通。

## 加账号

进「账号」页 → 点「添加账号」→ 用你的 Picsart 账号授权登录。

授权流程会打开 Picsart 的登录页，登录后复制页面上的授权码粘回来。

> 账号池里放几个号，就能同时跑几个任务。建议至少 2~3 个。

## 调用接口

激活后进「接入」页，那里有：

- 你的 Base URL
- 可一键复制的 curl 示例
- **「下载 .md」按钮** —— 一份完整的接口文档

把那份 `.md` 直接拖给 AI（Claude / ChatGPT / Cursor），它就能写出能跑的
调用代码 —— 不需要你再解释接口细节。

文档里写清了这些 AI 容易搞错的事：

- 轮询间隔 **10~15 秒**（写 `sleep(1)` 会被限流）
- 单任务耗时 **91 秒 ~ 23 分钟**，超时至少设 30 分钟
- `503` = 账号池全忙（等 30~60 秒重试），`429` = 瞬时撞车（按 `Retry-After` 退避）
- **接口不幂等**，网络异常先按 `id` 查再重发

## 配置项

全部通过环境变量，**都是可选的**：

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `3000` | 监听端口（平台会自动注入） |
| `DATA_DIR` | `./data` | 数据目录（账号、任务、激活凭证） |
| `PICSART_POOL_UPSTREAM_PROXY` | 空 | 调 Picsart 用的代理，如 `http://127.0.0.1:7890` |
| `PICSART_POOL_ADMIN_PASSWORD` | 空 | 设了就要求登录管理页（默认免登录） |
| `PICSART_POOL_API_KEYS` | 空 | 设了 `/v1/*` 就要带 Bearer key |

> **代理说明**：如果你的机器要靠代理才能连境外网站，设
> `PICSART_POOL_UPSTREAM_PROXY`。授权服务器的请求永远直连，不走代理。

## 常见问题

### Q：点「添加账号」后一片黑，只有 `{"error":""}`

旧版本的错误信息丢失 bug，**当前版本已修复**。如果你还看到这个，
说明跑的是旧代码，请更新到最新 Release。

### Q：重新部署后要重新激活

重新部署会重置应用目录，`data/` 里的激活凭证和账号数据会丢，所以需要
重新激活。

**所以：不要随便重新部署。** 要更新版本时先备份 `data/` 目录。

### Q：视频多久能出

实测 5 秒视频需要 **91 秒 ~ 23 分钟**，取决于上游排队。
不要以为卡住了。轮询间隔建议 10~15 秒。

### Q：任务一直排队不动

在「账号」页看可用账号数。一个账号同时只能跑一个任务，
只有 1 个号时，第二个任务必须等第一个跑完。

### Q：页面打不开 / 502

先检查启动命令是不是 `python workbuddy/entry.py`。

## 项目结构

```
app/                程序本体
  config.py         配置（站点知识已外置，源码里没有）
  upstream.py       调 Picsart 的接口层
  pool.py           账号池调度
  api_proxy.py      OpenAI 风格接口转发
  api_admin.py      管理接口
  docs.py           接口文档生成
  static/           前端
workbuddy/          部署适配层
  entry.py          ← 启动入口（必须用这个）
  gate.py           授权门（Ed25519 验签 + 配置解密）
  guard.py          激活拦截 + 诊断端点
  puburl.py         从 X-Forwarded-* 推导公网地址
  remote.py         把解密后的配置注入 app.* 模块
requirements.txt    依赖
部署说明.md          给部署者的详细说明
API文档.md           给调用方（和 AI）的接口文档
```

> **为什么源码里看不到 Picsart 的接口地址和参数规则？**
>
> 那些是逆向出来的结论，不在源码里。它们由授权服务器加密下发，
> 只有激活后才会解密到内存。所以这份源码本身没有商业价值 ——
> 有商业价值的是激活码背后那套配置。
